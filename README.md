Al definir la tecla r como el comando de reconfiguración de controles se le da el acceso al usuario para que diga que tecla quiere que haga que cosa; 
Ej: no me gusta que w sirva para llamar el comando de saltar así que lo puedo cambiar a que la tecla "SPACE" sea la que llama el comando de saltar.
